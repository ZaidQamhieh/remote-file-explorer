    Pair a phone

    Makes a one-time code for the RFE phone app. On the phone, add this PC's address, then enter the code. A code works once and stops working after 10 minutes. Anyone who sees it before then can pair a device, so show it only to the person pairing.

    Pairing code

    This pairing code has expired. Generate a new one.

    This login cannot create pairing codes. Only a session signed in with the account can; a computer paired with a code or approved on the PC cannot. Sign out and sign in with the account, or run rfe-agent pair on the PC.

    Generating a new code does not cancel an earlier one; each stops working when it is used or when its time is up. The code is shown here only: it is not saved or copied for you.
