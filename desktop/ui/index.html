Confirm the certificate

On the PC running the agent, run rfe-agent status and compare its fingerprint with this one. Trust it only if they match exactly.

Sign in

Use the agent account created with rfe-agent adduser. Signing in also registers this computer as a device.

·

On the PC running the agent, run rfe-agent pair and enter the code it prints. A code pairs this computer as an ordinary device: it can list and manage only itself.

Approve on the PC

On the PC running the agent, approve the request in the notification, or run rfe-agent pair requests and then rfe-agent pair accept. Approve only if the PC shows this same code.
